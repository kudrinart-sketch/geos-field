# GeoS Полевой для Android

[Скачать GeoS Полевой 0.1.8](https://raw.githubusercontent.com/kudrinart-sketch/geos-field/main/apk/GeoS-Android-0.1.8.apk) · [Описание выпусков](https://github.com/kudrinart-sketch/geos-field/releases)

Android 8.0 и новее. Установите APK поверх прежнего GeoS, не удаляя приложение: объекты и настройки сохраняются.

## Передача объекта коллеге

1. Откройте объект → **⋯ → Передать коллеге → Отправить**.
2. Отправьте ZIP через мессенджер, почту или системный обмен файлами.
3. На другом телефоне сохраните ZIP и выберите в GeoS **Принять объект**. Также можно открыть ZIP через пункт Android «GeoS Полевой».

Передаются описания скважин, номера ИГЭ, слои и прослои, координаты, даты, пробы, оба горизонта воды, зондирование и фото. После приёма можно продолжить работу и отправить объект обратно. Для приёма нужна версия **0.1.8 или новее**.

Перед загрузкой показывается состав объекта. Если объект уже есть, предлагается отдельная копия. Автоматического объединения изменений двух телефонов нет.

## Обновления

На главном экране приложения: **Обновления → Проверить обновления → Скачать обновление → Установить**. Первое обновление с версии 0.1.6 установите вручную. Установку подтверждает Android.

Сохранены два горизонта подземных вод с отдельными глубинами, датами и названиями. Для передачи двух горизонтов на ПК нужен GeoS 0.7.64 или новее.

Здесь хранятся установочные APK и сведения о версиях. Исходники приложения и данные объектов не публикуются.

Файл update.json используется приложением для проверки обновлений. APK проверяется по размеру, SHA-256 и подписи.
