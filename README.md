# GeoS Полевой для Android

[Скачать GeoS Полевой 0.1.7](https://raw.githubusercontent.com/kudrinart-sketch/geos-field/main/apk/GeoS-Android-0.1.7.apk) · [Описание выпусков](https://github.com/kudrinart-sketch/geos-field/releases)

Android 8.0 и новее. Установите APK поверх прежнего GeoS, не удаляя приложение.

В версии 0.1.7: два горизонта подземных вод с отдельными глубинами, датами и названиями. Для передачи двух горизонтов на ПК нужен GeoS 0.7.64 или новее.

На главном экране приложения: **Обновления → Проверить обновления**. Первое обновление с версии 0.1.6 установите вручную. Следующие версии можно скачивать из приложения; установку подтверждает Android.

Здесь хранятся установочные APK и сведения о версиях. Исходники приложения и данные объектов не публикуются.

Файл update.json используется приложением для проверки обновлений. APK проверяется по размеру, SHA-256 и подписи.
