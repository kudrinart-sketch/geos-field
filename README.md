# GeoS Полевой для Android

[Скачать GeoS Полевой 0.1.10](https://raw.githubusercontent.com/kudrinart-sketch/geos-field/main/apk/GeoS-Android-0.1.10.apk) · [Описание выпусков](https://github.com/kudrinart-sketch/geos-field/releases)

Android 8.0 и новее. Установите APK поверх прежнего GeoS, не удаляя приложение: объекты и настройки сохраняются.

## Что изменилось в 0.1.10

- У песка вместо общего «Состояние» указана **«Плотность песка»**: рыхлый, средней плотности или плотный. Водонасыщение заполняется отдельно.
- Если заполнено только водонасыщение, замечание сообщает: **«Не заполнено: плотность песка»**. Кнопка под замечанием сразу открывает выбор плотности.
- Кнопка **«плотный»** больше не сжимается до полоски. Исправление действует и для последних плиток в других неполных рядах.

Обновление устанавливается поверх 0.1.9. Подпись APK прежняя; удалять приложение не нужно.

## Передача объекта на другой телефон

1. Откройте объект → **⋯ → Передать на другой телефон → Отправить**.
2. Отправьте ZIP через мессенджер, почту или системный обмен файлами.
3. На другом телефоне сохраните ZIP и выберите в GeoS **⋯ → Принять объект**. Также можно открыть ZIP через пункт Android «GeoS Полевой».

Передаются описания скважин, номера ИГЭ, слои и прослои, координаты, даты, пробы, оба горизонта воды, зондирование и фото.

При приёме можно создать **новый объект** или **добавить скважины в свой объект** (если объект тот же, но назван по-другому): по каждой скважине — добавить, пропустить или записать под другим номером (184 → 184-к). Замена ранее принятых данных выполняется только по команде «Обновить». Повторно переданные скважины отмечаются «принята раньше». Уже принятый объект можно разнести: **⋯ → Перенести скважины в другой объект**. Для этого нужна версия **0.1.9 или новее**.

## Обновления

На главном экране приложения: **⋯ → Обновления → Проверить обновления → Скачать обновление → Установить**. Установку подтверждает Android.

Здесь хранятся установочные APK и сведения о версиях. Исходники приложения и данные объектов не публикуются.

Файл update.json используется приложением для проверки обновлений. APK проверяется по размеру, SHA-256 и подписи.
Проверки 0.1.10: 130 автоматических тестов без ошибок и пропусков; проверка Android — 0 ошибок, 38 прежних предупреждений. На эмуляторе проверены установка поверх 0.1.9 с сохранением всех записей, выбор и повторное открытие плотности, сохранность водонасыщения и остальных скважин и проб. Перед публикацией повторно проверены подпись APK и совместимость подписи с 0.1.9. Физический телефон и печать на CT221B в этой проверке не участвовали.
